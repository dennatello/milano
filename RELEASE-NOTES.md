# Milano 1.0 RC8 — тестовая сборка

[Русский](#russian) | [English](#english)

<a name="russian"></a>

## Русский

Первая публичная beta для обратной связи. Apple Silicon, macOS 13+. Версия приложения 1.0, build 9.

В сборке: плавающие заметки, быстрые фразы с группами и профилями, глобальные хоткеи, шаблоны с переменными, локальный JSON import/export, резервные копии и исправление раскладки RU ↔ EN.

Это бесплатная тестовая сборка с отключённым лицензированием. Developer ID, notarization, автообновления и приём оплаты пока не подключены. Полная совместимость с редакторами и версиями macOS ещё проверяется.

Скачайте **Milano-1.0-rc8-preview-arm64.dmg** в Assets, затем прочитайте [инструкцию установки](https://github.com/dennatello/milano/blob/main/INSTALL.md). Файл **SHA256SUMS.txt** содержит контрольную сумму образа. Автоматические архивы **Source code** содержат только материалы страницы; исходники приложения закрыты.

Перед обновлением экспортируйте свои данные из Milano. Вопросы и повторяемые ошибки можно оставить в [Issues](https://github.com/dennatello/milano/issues).

## English

The first public beta for feedback. Apple Silicon, macOS 13+. App version 1.0, build 9. The current app interface is in Russian.

Includes floating notes, quick phrases with groups and profiles, global hotkeys, templates with custom fields, local JSON import/export, backups and Russian ↔ English keyboard layout correction.

This is a free test build with licensing disabled. Developer ID signing, Apple notarization, automatic updates and payments are not available yet. Testing across editors and macOS versions is still in progress.

Download **Milano-1.0-rc8-preview-arm64.dmg** under Assets, then follow the [English quick start](https://github.com/dennatello/milano/blob/main/README.en.md#quick-start). **SHA256SUMS.txt** contains the DMG checksum. GitHub's automatic **Source code** archives contain only the public page materials; the application source code is closed.

Export your data from Milano before updating. Questions and repeatable bugs can be reported in [Issues](https://github.com/dennatello/milano/issues).
