# Данные Milano RC8

Milano не требует аккаунта и не отправляет заметки, фразы или введённый текст на сервер разработчика. В текущей сборке нет облачной синхронизации и сетевой аналитики.

## Что хранится на Mac

- Заметки, фразы, профили и настройки: `~/Library/Application Support/Milano/state.json`.
- Локальные резервные копии: папка `Backups` рядом с данными. Хранятся десять последних копий.
- Экспорт JSON: в выбранном вами месте.

Эти файлы не зашифрованы самим приложением. Экспорт и резервные копии содержат ваши тексты.

## Доступ к вводу

«Универсальный доступ» используется для чтения доступного текстового поля, выделения заменяемого фрагмента и вставки текста. Для вставки в некоторые приложения Milano временно использует системный буфер обмена и затем восстанавливает прежнее содержимое, если пользователь за это время не скопировал что-то новое.

«Мониторинг ввода» нужен автоматической раскладке, чтобы заметить границу слова. Для анализа используется ограниченный фрагмент текста возле курсора; история набора не сохраняется. Защищённый ввод проверяется, исключения приложений настраиваются пользователем.

## Диагностика

Встроенная диагностика запускается вручную на пять минут. Её локальный отчёт содержит номер сборки и фиксированные счётчики этапов обработки. В него не записываются текст поля, названия документов, адреса страниц и история нажатий. Отчёт не отправляется автоматически.

Сообщения и вложения, которые вы сами публикуете в GitHub Issues, публичны и обрабатываются GitHub по его правилам. Для обращения об ошибке используйте вымышленные примеры.
