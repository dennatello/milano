# Milano для Mac

**Заметки поверх окон. Готовые ответы по горячей клавише. Исправление русской и английской раскладки.**

Milano — небольшая нативная рабочая панель для тех, кто часто отвечает клиентам, ведёт переписку и держит важную информацию под рукой.

**[Скачать тестовую сборку для Apple Silicon](https://github.com/dennatello/milano/releases/tag/v1.0.0-rc8)** · [Установка](INSTALL.md) · [Сообщить о проблеме](https://github.com/dennatello/milano/issues)

## Что умеет

- **Плавающие заметки:** несколько окон, закрепление поверх других приложений, размер, прозрачность, сворачивание и автосохранение.
- **Быстрые фразы:** группы, поиск и собственные глобальные горячие клавиши.
- **Рабочие профили:** «Продажи», «Поддержка» и «Личное» с ручным переключением.
- **Шаблоны:** дата, время, буфер обмена, место курсора и поля для заполнения перед вставкой.
- **Умная раскладка RU ↔ EN:** автоматическое исправление по границе слова, ручное исправление и отмена повторным хоткеем. Автоматический режим изначально выключен.
- **Локальные данные:** JSON-экспорт, импорт и резервные копии. Без обязательного аккаунта и облачной синхронизации.

Например, фраза `Здравствуйте, {name}! Заказ {order} готов.` перед вставкой попросит заполнить имя и номер заказа.

## Текущая версия

**1.0 RC8, build 9 — бесплатная тестовая сборка.** В ней отключено лицензирование. Семидневный trial и покупка пока не предлагаются.

Нужен Mac с Apple Silicon и macOS 13 или новее. Intel и Windows не поддерживаются. Минимальная версия macOS задана в сборке; проверка на всех поддерживаемых версиях системы ещё не завершена.

У этой beta нет Developer ID и notarization: macOS может заблокировать обычный первый запуск. Перед скачиванием прочитайте [инструкцию установки и ограничения](INSTALL.md). Это раннее тестирование, а не финальный платный релиз. Совместимость со всеми редакторами не обещается.

## Данные и разрешения

Заметки и фразы хранятся на вашем Mac. Для вставки нужен «Универсальный доступ», для автоматической раскладки — также «Мониторинг ввода». Milano не отправляет введённый текст разработчику. [Подробнее о данных](PRIVACY.md).
